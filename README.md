# Security Resource Kit feedback

Use Issues for public training corrections and feature requests. The training site supplies topic, revision, and subsection identifiers from its Report an issue link. Include those coordinates and a public primary reference when possible.

**This repository is public.** Do not include tenant IDs, usernames, email addresses, device names, unredacted portal screenshots, credentials, live tokens, customer data, or incident evidence. Use synthetic examples only.

Send sensitive security/privacy reports through the training site's private Contact form instead. Site sign-in is separate from GitHub sign-in; deleting a learner account does not remove GitHub issues.
